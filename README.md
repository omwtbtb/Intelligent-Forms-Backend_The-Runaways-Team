# Intelligent Forms Backend - The Runaways Team

## Description
This is the backend for the **Intelligent Forms** application. The application uses **Azure Document Intelligence** to scan identity documents and auto-fill forms, automating the data extraction process and reducing manual input.

## Technologies Used
- **C#**: The programming language for backend development.
- **ASP.NET Core**: Framework for building the backend API.
- **Azure Document Intelligence**: AI service used for scanning and extracting data from identity documents (e.g., using prebuilt models for ID documents).
- **Cosmos DB**: A NoSQL database service used for storing and managing data.
- **Entity Framework Core**: ORM for interacting with databases.
- **CI/CD with Azure Web App**: The project is configured for continuous integration and deployment using **Azure Web App**, automating the deployment process.

## Usage
This project was part of a competition and is not intended for installation. However, you can explore the source code to understand how the backend was implemented.
